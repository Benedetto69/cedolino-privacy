# Svelapaga — Informativa privacy e supporto

Pagine pubbliche dell'app iOS **Svelapaga** (nome di sviluppo: Cedolino; l'indirizzo resta `cedolino-privacy`):

- Informativa privacy: https://benedetto69.github.io/cedolino-privacy/
- Supporto: https://benedetto69.github.io/cedolino-privacy/support.html

Il testo descrive il comportamento verificato dell'app (audit e verifica del 12/10/2026):
elaborazione sul dispositivo, nessuna raccolta di dati da parte dello sviluppatore attraverso l'app,
archivio compreso nei backup di iCloud o del computer se attivi, connessioni verso GitHub (tavole
fiscali pubbliche) e Apple (acquisti), assistenza via email. Lo storico delle modifiche è in git.
